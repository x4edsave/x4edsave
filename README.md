===
using the command line, pass two parameters - the xml file name and additional parameters, if necessary
, "ALL" (or optionally) "nologs xenonup nomods nodef nocargo"
all parameters in single quotes
Changing player ships is not disabled

Makes changes to the save file x4:foundations v9.0 only
It only works with the save file

It will add in-game modifications to all player's ships and xenons (according to the selected program code).
Removes in-game modifications from all non-player ships.
Removes active and passive protection from all non-player and non-xenon stations (optional).
It's the same with cargo at the stations.
Together with the modification of Xenon ships, it will push full holds of goods into Xenon stations.
It will remove all cargo from non-player and non-xenon stations. be careful - the economy will fall into a deep crisis, the production of ships should stop for a long time. I didn't check it.

ps. immediately after the start of the test game, wait 3-5 minutes, maybe more, only then save and use
